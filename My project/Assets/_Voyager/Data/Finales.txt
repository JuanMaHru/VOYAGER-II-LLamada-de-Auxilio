# ============================================================================
#  FINALES DE VOYAGER II
#
#  Al terminar la partida se revisan los finales de MAYOR a MENOR prioridad y sale
#  el primero que cumpla sus requisitos. A igual prioridad, gana el que está más arriba.
#  Debajo del final se muestran hasta 3 reacciones de los alienígenas (Reacciones.txt).
#
#  Cómo se usa:
#   1. Editá este archivo.
#   2. En Unity: Voyager → Actualizar tolerancia, finales y reacciones
#
#  Formato de cada final:
#   [NombreSinEspacios]              → crea la ficha Data/Endings/Ending_NombreSinEspacios
#   titulo: Título que ve el jugador
#   prioridad: 400
#   modo: todas | alguna            → requisitos combinados con Y (todas) u O (alguna). Por defecto: todas
#   texto: Una línea del texto final (podés poner varias líneas "texto:")
#   reacciones: no                  → no mostrar reacciones alienígenas (ej: si la sonda nunca llegó)
#   defecto: si                     → final que sale si no se cumple ningún otro (solo uno)
#
#  Requisitos posibles:
#   aprobada: Nombre de la propuesta         (si el nombre se repite, usá categoria/Nombre)
#   rechazada: Nombre de la propuesta
#   aprobadas_de_region: eeuu >= 7           (en toda la partida)
#   aprobadas_de_categoria: comida >= 3      (en toda la partida)
#   stat: tolerancia >= 70
#   relacion: europa <= -30
#   alguna_region: <= -30                    (alguna región con relación <= -30)
#   flag: despedido
#   sin_flag: despedido
#
#  Operadores: >=  >  ==  !=  <=  <
# ============================================================================
